## Scope And Limits

The compiled engine is the production TealScript path. Package evidence does
not by itself prove that every app host supplies each request provider, library
registry, or worker bridge. The trace harness is ready for a recording; it
cannot manufacture TradingView ground truth. Realtime scheduling, provider
revisions, exchange calendars, unclosed higher-timeframe bars, and
broker-emulator sequencing remain evidence-dependent.
