## Invariants

- Compiled is the only TealScript execution engine.
- Unsupported compiled execution fails loudly and keeps `RuntimeProfile.fallbackReason`/`fallbackDiagnostics` visible.
- Missing request providers remain warnings; unsupported execution remains errors.
- Runtime sites that continue after ordinary per-bar errors must increment swallowed-error accounting and retain the first site/message/bar index.
- User-facing visual strings are labels, not identity. Plot and alertcondition identity must come from declarations/call sites while preserving first-occurrence legacy plot IDs for persisted Tealchart style overrides.
- Missing Pine declaration precision is `undefined`; Tealchart decides display precision at label render time.
- Corpus reports use repo-root-relative output paths so `yarn workspace` cannot create nested report trees under `packages/tealscript/packages/`.
- New product-path evidence must reuse the shared output comparator; do not write a second definition of equivalent output.
