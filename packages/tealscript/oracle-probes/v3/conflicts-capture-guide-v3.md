# Conflict capture guide v3

Six additional scripts; this supplement does not replace the existing 73-script v3 outcome bundle. Sources/hashes/columns: `conflicts-outcomes-manifest-v3.json`. Competing predictions: `conflicts-expected-outcome-v3.json`. All plot calls use `display.data_window`; largest script has36 plots. CF015 additionally has two visible hline scale controls, six boxes and three labels, below the60 plot-count limit.

Use BINANCE:BTCUSDT, 2-minute standard candles, UTC, Bar Replay off. Load at least100 bars and record dataset start, reset time and actual live candle opening. Run each unchanged script alone; capture compile/runtime diagnostics with exact source line, code, full text and failing bar/time if exposed. On success export all loaded indicator columns to untouched timestamped CSV; record strict historical cutoff and retain missing cells. Save screenshots and logs alongside the attempt. A native error before outputs is valid evidence; an unrelated setup/helper failure remains an instrument failure. Local parser/checker screening is not native authority.

1. `conflicts-CF015-wrap-pairs-v3.pine`: screenshot the entire dedicated pane with its six boxes. Each row compares NONE on the left with AUTO on the right: fixed18, integer0, size.auto. Default width5bars; keep both boxes at the same width. Show at least25 latest bars and y0..100. Require visible fixed18 wrapping/overflow as a positive control. If it does not overflow, keep the attempt and capture an additional explicitly recorded narrower zoom/width; never treat a nondiscriminating screenshot as a settlement. Compare lines, font size, clipping and overflow in the two auto rows. No getter or CSV proves text wrapping. Even a clear interaction outcome cannot prove which misspelled token the documentation author intended.
2. `conflicts-CF015-wrap-as-size-v3.pine`: isolate text.wrap_auto as text_size. Record its native admission/error separately so rejection cannot mask the paired visual script. String aliases may make size.auto and text.wrap_auto indistinguishable. The sentinel establishes execution only.
3. `conflicts-CF019-default-row-v3.pine`: distinct3x3 matrix101..303, omitted remove_row index. Retain removed0..2, remaining2x3, dimensions and controls. Removed[101,102,103] means first; [201,202,203] middle; [301,302,303] last. Remaining values independently confirm deletion/order. An error must be preserved, rather than editing in an index.
4. `conflicts-CF020-default-col-v3.pine`: same matrix, isolated omitted remove_col. Removed[101,201,301] means first; [102,202,302] middle; [103,203,303] last. Remaining3x2 and dimensions independently confirm it. Separate script preserves one outcome if the other rejects.
5. `conflicts-CF036-native-guards-v3.pine`: export native high/low, previous high/close, divergent-guard flag/count, builtinATR5 and both documented guard/RMA candidates. Settlement requires covered_count>0 AND different candidate outputs; compare missingness and subsequent recurrence. Ordinary BTCUSDT2m clean OHLC is expected to produce coverage0, meaning UNSETTLED. Editing synthetic high/close variables does not alter ta.atr's native context. Retain a zero-coverage result as evidence of domain absence, not agreement with either authority.
6. `conflicts-CF046-hole-runs-v3.pine`: export all36 columns and at least100bars from index0. Five controlled sources exercise eight leading holes, three consecutive holes, eight consecutive holes, alternating holes and leading+consecutive holes at length5. Each has native WMA, exact raw-slot reference example, compact-last-valid/hold candidate, immediate-prior-filled raw slots with current-hole suppression, and last-valid-filled raw slots with current-hole suppression. Missingness matters as much as finite weights. Consecutive gaps distinguish one-step fill from carry-forward fill, which single-hole v2 rows could not. Leading/long gaps distinguish startup/recovery. Preserve any third outcome instead of guessing a global policy. JSON includes independent first93-bar predictions for an additional compact/na-on-current-hole candidate.

Write returned attempts under `captures/v3/` in this supplement's archive folder, recording source hash, ticker/timeframe/chart, input defaults, dataset start, reset/live/export times, strict historical cutoff, CSV filename and diagnostic/visual paths. Preserve every attempt. CF015 needs screenshots; successful numeric scripts need CSVs containing every declared column. No capture or outcome is prefilled here.
